## 启动

运行 `node server.cjs --review`，打开 http://127.0.0.1:4186/ 。默认 `node server.cjs` 使用 4185。

## 玩法

首页可选 **自由对战** 或 **闯关模式**，并选择热血摇滚/舒缓小镇录音。自由对战任选 13 位英雄及 14 位对手；闯关按固定顺序连续挑战全部 14 位，胜利恢复 2 点能量（上限 5），失败可满血重试当前关，最后一关显示通关。刷新或返回首页后重新开始一轮，不保存进度。

- A/D、左右方向键：移动；W/↑：跳跃；按住 S/↓：下蹲。
- **U / I / J / K**：四个技能，顺序与屏幕按钮一致。R 重开，Esc 暂停。
- 身体接触不扣血，怪兽只有主动攻击命中才会造成伤害。近身反击、跳跃/下蹲闪避、距离控制和更短技能间隔使对手更主动；每次攻击保留可躲开的预警。
- 触屏提供八个独立按钮，横屏收起侧栏、固定操作区；全屏按钮需用户点击。实际战场从 1100 扩至 1500 单位，1300 宽视窗随英雄平滑横移。
- 每局有 VS / READY / FIGHT 开场，配报幕与战斗喊声；命中增加短停顿、震屏及受击反馈。配音为本机语音生成的英文街机喊声，不是原作演员或影视录音。
- 角色前进、后退、跳跃、落地、下蹲、出招与受击使用轻量 2D 分段动画。后退仍朝向对手；并非逐帧手绘的完整格斗动作表。
- 所有 27 位角色都有精细全身 PNG；14 位对手的默认形态全部接入新标准。孙悟空变身时保留原来的动物轮廓动画。显示以有效透明边界统一高度/脚底，诺亚双翼和悟空翎羽按装饰高度补偿。
- 鼠标悬停或键盘聚焦角色卡，显示人物介绍及全部技能说明。战斗内可暂停、切换音乐、返回首页；切换后台自动暂停。

## 文件与来源

`model.mjs` 负责战斗，`combat-kit.mjs` 负责技能和按键，`campaign.mjs` 负责关卡推进，`game.mjs` 负责画面/输入/音频。

原作技能依据见 `CHARACTER-SOURCES.md`。内置 image_gen 生成记录与完整提示词见 `assets/fighters/GENERATION.md`、`assets/fighters/MONSTERS-GENERATION.md`。附件原图保留在 `assets/portraits/`。

舒缓配乐为 Bobjt 的 Peacefull Ville (2023)，CC0：https://opengameart.org/content/peacefull-ville 。语音生成记录见 `assets/voices/README.md`。素材从本地按需加载，无构建依赖。

## 验证

- `node self-test.mjs`：52 技能、182 个受控阵容胜利/重开、所有怪兽预警、14 种失败、跳蹲碰撞与各状态。
- `node test-boss-xingxing.mjs`：Boss/星星四技能、范围、伤害、恢复和终局。
- `node test-arcade.mjs`：UIJK、14 位接触无伤害、主动反击、AI 闪避、14 关推进/回血/失败/重复提交保护。
- 浏览器与媒体核验记录：`evidence/arcade-review.json`。批量模型测试不代表人工打通全部 182 个组合。

小米 15 Pro 真机、多指触控和扬声器听感未实测。高清 PNG 未压缩，移动网络首次加载成本仍需关注。旧版 verify-*.js/cjs 全集没有运行。
