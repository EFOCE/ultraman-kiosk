## 只用一个鼠标即可玩

1. 封面点击「开始游戏」，在左侧滚动选择英雄，在右栏选择对手（窄窗口点击右边「怪兽」展开抽屉），再点击「开始守护」。窄窗口也保留左侧独立滚动栏。
2. 点击战斗画面地面，英雄会走到目标位置并停下；再次点地面可换目标、转身。行走途中可点击下方技能，或按住光线连续发射。
3. 也可按住左右按钮移动，松开停止；手动移动会取消地面目标。选择角色、重开、胜负、窗口失焦或鼠标离开页面会清除临时输入与移动目标。
4. 点「重新开始」或结算后的「再玩一次」，保留英雄/对手并清空投射物、状态、冷却。点「声音」切换音效，点「音乐」打开音乐设置。

## 唐僧的四招

布牛是带缝线与布块的原创布偶牛；唐僧使用袈裟、冠帽和禅杖造型，替换原来的两个对手位置，不增加总数。

唐僧循环使用四招，每招先预警1.15秒，出招后休息3.2秒。攻击标记锁定预警开始时的位置，可提前离开；两次控制间隔足够恢复。

- 紧箍咒：金圈范围65，命中伤害1并使英雄移速降为30%，持续0.9秒。
- 佛光护盾：护盾持续1.3秒，阻挡伤害及定身弹；结束后可正常击败。
- 禅杖震波：沿预警方向发出可见地面冲击，伤害1。
- 莲花法阵：地面标记范围95，预警后生效，伤害2；离开标记即可躲避。

## 四种天气

天气选项：随机（默认）、晴天、下雨、雷雨、龙卷风。每次开始或重开，随机模式重新抽取四种天气之一，可能连续抽中同一种；手选模式保持指定天气。上方显示本局天气。

天气仅改变视觉，不改变移动、伤害、生命或冷却。雨线、云层、局部柔和闪电与卡通龙卷风绘制在角色和预警后方，不覆盖按钮；雷雨不使用全屏频闪。重开归零天气动画时间，系统减少动态效果设置会冻结天气运动。无需天气 API。
