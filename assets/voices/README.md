# 街机风格配音

2026-11-07，用本机 System.Speech 的 Microsoft Zira Desktop 语音、Rate=1 生成 9 个 WAV。不是《拳皇》或奥特曼影视原声，也没有仿冒原演员。

- ready: Ready!
- fight: Fight!
- winner: You win!
- ko: Knock out!
- ha: Ha!
- hya: Hi yah!
- take: Take this!
- power: Power!
- hurt: Ah!

游戏使用 Web Audio 解码预载，角色按音域改变 playbackRate；报幕优先，短喊声限频。暂停、静音、后台与返回首页会停止音频。手机无需安装语音包。

舒缓音乐：Bobjt 的 Peacefull Ville (2023)，CC0，完整录音循环。
